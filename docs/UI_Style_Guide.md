# UI Style Guide

## Visual Direction

The application uses a dense manufacturing dashboard style inspired by the provided reference, but not a visual copy. The emphasis is fast operational scanning: dark industrial surfaces, cyan status highlights, compact KPI cards, rich data tables, and clear exception states.

## Principles

- Prioritize information density without becoming unreadable
- Surface plan-versus-actual metrics early
- Use color to signal action, not decoration
- Keep mobile layouts functional by collapsing data into prioritized cards

## Core Patterns

- KPI header cards for plant and schedule health
- Dense operational tables with inline progress and status tags
- Filter bars above every master or transaction list
- Right-sized action buttons for create, export, and workflow transitions

## Status Colors

- Good: emerald
- Warning: amber
- Exception: rose
- In progress: cyan
